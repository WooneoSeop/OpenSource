# OpenSource Python Project

## 1. 개요

* 목적: 라이브러리를 활용하여 무선 신호 전파를 시각화하는 Python 프로그램 구현
* 개발 환경:

  * OS: Windows
  * IDE: VS Code

## 2. 프로젝트 설명

본 프로젝트는 지도 이미지 위에 건물(장애물)과 기지국 위치를 사용자가 직접 지정하고,
자유공간 손실(FSPL)과 건물 차폐 효과를 고려하여 **무선 신호 세기 분포를 시각화**하는 프로그램이다.

사용자는 마우스 입력을 통해 건물 윤곽과 기지국 위치를 지정할 수 있으며,
계산된 신호 세기는 컬러맵 형태로 출력된다.

## 3. 디렉토리 구조

```
OpenSource_Python_Project/
 ├─ src/
 │   ├─ main.py        # 전체 실행 진입점
 │   ├─ paint.py       # 건물 및 기지국 위치 입력 (마우스 인터랙션)
 │   ├─ cal.py         # 신호 세기 계산 및 시각화
 │   └─ delete.py      # 좌표 파일 초기화
 ├─ 1.png              # 배경 지도 이미지
 └─ polar_coordinate.txt  # 건물 좌표 저장 파일
```

## 4. 사용 기술 및 라이브러리

* Python 표준 라이브러리: math, os, sys
* NumPy: 격자 데이터 생성 및 연산
* Matplotlib: 이미지 출력 및 신호 세기 시각화
* PIL (Pillow): 이미지 로드
* Shapely: 선분-다각형 교차 판별 (건물 차폐 여부 판단)

## 5. 구현 기능

* 마우스 클릭을 이용한 건물(다각형) 좌표 입력
* 휠 클릭을 통한 기지국 위치 설정
* 자유공간 경로 손실(FSPL) 기반 신호 세기 계산
* 건물과의 교차 여부에 따른 추가 손실 반영
* 지도 위 신호 세기 분포를 컬러맵으로 시각화

## 6. 사용 방법
1. `main.py`를 실행한다.
2. 지도 이미지가 표시되면 마우스 입력을 통해 다음 작업을 수행한다.
   - 좌클릭: 건물의 꼭짓점 좌표를 순서대로 입력
   - 우클릭: 입력한 꼭짓점을 하나의 건물로 저장  
     (단, 하나의 건물을 구성하는 좌표 입력이 완료된 후 우클릭해야 함)
   - 휠 클릭: 기지국 위치 설정
3. 모든 건물과 기지국 위치를 설정한 후 프로그램을 종료한다.
4. 저장된 좌표 정보를 기반으로 신호 감쇠를 고려한 신호 세기 분포가 계산되며,
   지도 이미지 위에 시각화 결과가 출력된다.
5. 배경 이미지는 프로젝트 최상위 디렉토리에 `1.png` 파일명으로 저장된 이미지를 사용하며,
   다른 이미지를 사용하고자 할 경우 동일한 파일명(`1.png`)으로 교체하고 delete.py를 통해 좌표를 초기화 한 후 사용하면 된다.

6. 좌표 초기화 (선택)

```bash
python delete.py
```

## 7. 실행 결과

* 지도 이미지 위에 건물 윤곽과 기지국 위치 표시
* 신호 세기가 강할수록 녹색, 약할수록 적색으로 시각화됨

## 8. 참고 사항

* 건물은 최소 3개 이상의 점으로 이루어진 다각형이어야 함
* 신호 세기 계산은 단순화된 모델로 실제 환경과 차이가 있을 수 있음
* 이미지 해상도에 따라 계산 시간이 증가할 수 있음
